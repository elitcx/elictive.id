## Overview

This is the official landing page for **elictive.id** — a digital studio offering branding, graphic design, and web development services tailored for local small businesses (UMKM) in Solo Raya, Indonesia.

Built and maintained by the founder as both a client-facing storefront and a live demonstration of technical capability.

---

## Services

- **Brand Identity**
- **Social Media Design**
- **Website Design**

---

## Tech Stack

- **HTML5 / CSS3 / Vanilla JS** — no framework overhead for a fast, lightweight page
- **Figma** — design source files
- **Hosted via** — Vercel
